California housing pricing Prediction model

A Machine Learning project that predicts the prices of houses in california based on:

* HouseAge
* AveRooms
* AveBedrms
* Population
* AveOccup
* Latitude
* Longitude

How it works
The model learns patterns from existing data and uses those patterns to predict the price of houses.

Prediction: Price of houses

Model Used
Linear Regression — a multiple classification algorithm used to predict outcomes with more than two possible results.

Tools
Python • Pandas • NumPy • Matplotlib • Scikit-learn
